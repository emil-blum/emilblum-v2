(Mind)Space

View

An experiment-in-process — locally hosted project management / creative process canvas tool built to help me see everything I'm working on at the same time, without the need to navigate through folders. Includes automatic launches of local servers for dev projects, local Whisper speech-to-text model integration for notes, and many other bells and whistles.

Vault of Vör

View

This project began as a fascination with steganography after I learned it's possible to hide text and audio in the pixels of an image. VoV lets you upload any image and encode secret messages within it with military-grade security. Good fun for encoding memories in photos or sharing top-secret messages as a whistleblower to journalists — your choice.

3DGS Forest Bathing

View

An experimental website created to test 3D Gaussian Splat embedding on an educational website. Only fully functional on a desktop due to the heavy 3D splat file.

Reveil

View

An experimental awareness tool for discovering how much information your device, browser, and computer automatically broadcast for anyone to see, if they wish. Plus additional face and audio recognition visualisers for the fun of it.

Page Runner

View

Speed-reading tool based on the Optimal Recognition Point concept, first introduced by Frank Waldman's Spritz app. Useful for reading .md, .txt, and .docx files.

Gradient Tool

View

I needed to have gradients for a project, but found it frustrating to create them in Adobe CC, so I made this. Since I have it, I have never again needed to make a gradient for anything, but I'll use it when I do.

I'm fascinated by procedural music-making, and knowing a coloured pixel holds a mathematical value, I decided to map those values to notes and sounds for endless fun.
